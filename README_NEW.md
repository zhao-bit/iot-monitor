# 物联网智能监控系统 - 完整版

一个基于纯 HTML5、CSS3、JavaScript 开发的物联网智能监控系统，具有现代化的深色科技感界面。

## 🎨 设计特点

- **深色科技感主题**：深蓝/灰/科技蓝渐变背景
- **现代化UI设计**：卡片式布局、渐变按钮、微动画效果
- **响应式设计**：完美适配PC、平板、手机
- **粒子背景效果**：登录页面动态粒子背景
- **光晕边框效果**：登录框和重要元素带光晕动画

## 📁 项目结构

智能控制系统/

## 🚀 功能模块

### 1. 登录界面 (`login.html`)

- ✅ 表单验证（用户名、密码）

- ✅ 记住用户名功能
- ✅ 登录按钮悬停和点击动画

## 🎯 技术实现

### 登录页面
- **粒子背景**：使用Canvas绘制动态粒子效果和连接线
- **表单验证**：实时验证用户名和密码，带错误动画
- **登录处理**：模拟登录请求，支持记住用户名

### 视频识别
- **文件上传**：支持拖拽和点击上传，文件大小验证
- **视频播放**：使用HTML5 video元素
- **检测叠加**：使用Canvas在视频上绘制检测结果
- **结果列表**：实时显示识别结果，支持清空

### 视频记录
- **数据存储**：使用localStorage存储视频记录
- **搜索筛选**：实时搜索和状态筛选
- **分页处理**：自动分页，支持翻页
- **详情查看**：模态框显示视频详细信息

### 实时检测
- **模拟视频流**：使用Canvas绘制模拟视频画面
- **检测循环**：定时检测，显示检测结果
- **报警系统**：检测到异常时自动报警
- **统计更新**：实时更新检测统计数据

### 实时记录
- **数据管理**：记录所有检测事件和报警
- **智能筛选**：支持多维度筛选
- **统计分析**：实时统计各类记录数量
- **数据导出**：支持导出为CSV文件

### 个人中心
- **设置管理**：主题、通知、语言设置
- **数据统计**：使用统计和图表占位
- **登录历史**：显示历史登录记录

## 🎨 样式特点

### 深色科技感主题
- 深色背景：`#0f172a`, `#1e293b`, `#334155`

- 悬停动画：卡片、按钮悬停时上浮
- 点击动画：按钮点击时缩放

### 响应式设计
- **桌面端** (> 1024px)：完整布局
